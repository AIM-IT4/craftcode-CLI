01 / WORKFLOW

Built like a serious coding agent.

Persistent sessions

Resume, search, rename, fork and export conversations per workspace.

Parallel subagents

Bounded explorer, reviewer, tester and research agents run independently and report back.

Inline edits

Red/green code diffs appear directly under edit cards, with checkpoints and undo.

Native copy

Drag-select terminal text and Ctrl+C normally. Mouse capture is optional, never forced.

Permission first

Ask, Edit, Auto and Read-only modes govern writes, shell commands and MCP actions.

Token aware

Request/session/day/plan usage, lazy skills, bounded file reads and context compaction.

Open extension model

SKILL.md, Claude-style plugins, stdio/HTTP MCP, OAuth and project instructions.
