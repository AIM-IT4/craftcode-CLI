# Code of Conduct

Craft Code is intended to be a constructive, technically rigorous and welcoming open-source project.

## Expected behavior

- Be respectful and specific in technical disagreement.
- Critique ideas and code, not people.
- Do not harass, threaten, discriminate, dox or publish private credentials/data.
- Assume good intent while still holding code and claims to a high technical standard.

## Enforcement

Maintainers may edit, hide or remove contributions that violate these expectations and may restrict participation for repeated or severe violations.

For conduct issues that should not be public, contact the repository owner privately through GitHub.
