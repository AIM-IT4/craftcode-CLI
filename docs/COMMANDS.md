# Command reference

## Sessions

- `/sessions` — searchable session picker
- `/resume` — resume latest session
- `/session name <title>`
- `/session fork`
- `/session export`
- `/session delete`
- `/new`

## Agent controls

- `/mode` — Plan / Build picker
- `/model` — model picker
- `/effort` — Low / Normal / High
- `/permissions` — permission preset picker
- `/agents`
- `/agent spawn <role> <task>`
- `/team [count] <task>`

## Context and project

- `/status`
- `/context`
- `/compact`
- `/init`
- `/instructions`
- `/instructions reload`
- `@path/to/file` — attach selected workspace file

## Extensions

- `/skills`
- `/plugins`
- `/plugin marketplace add <owner/repo>`
- `/plugin install <name@marketplace>`
- `/connect`
- `/mcp`

## Git / shell

- `/diff`
- `/checkpoints`
- `/undo`
- `!git status` — shell shortcut through normal permissions
